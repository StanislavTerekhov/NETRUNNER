NETRUNNER — локальная рабочая станция ИИ для разработчика.

Установка полностью автоматическая. Установщик сам:
  • ставит программу NETRUNNER → %LOCALAPPDATA%\Programs\NETRUNNER
  • ставит движок llama.cpp (видеокарта NVIDIA и процессор) с библиотеками Visual C++ и ripgrep
    → %USERPROFILE%\NETRUNNER\runtime
  • скачивает все модели (около 85 ГБ) и проверяет каждый файл по SHA-256 → %USERPROFILE%\NETRUNNER\models
    Модели Qwen — с Hugging Face, модели NETRUNNER FORGE — со страницы релизов проекта на GitHub.
  • ставит Git for Windows, если его нет на компьютере (нужен агентам)

Во время установки нужен интернет. Загрузка займёт от получаса до нескольких часов, в зависимости от скорости
подключения. Если связь прервётся, установщик повторит загрузку; при повторном запуске уже скачанное не качается
заново. После установки интернет больше не нужен: программа работает полностью офлайн.

Минимальные требования:
  • Windows 10 (1809) или Windows 11, 64 бит; процессор x64 с 4 ядрами
  • оперативная память 16 ГБ — работает чат; агентам на Qwen3-Coder-Next нужно 64 ГБ
  • 100 ГБ свободно на диске C:
  • видеокарта не обязательна: без NVIDIA модели работают на процессоре, медленно

Рекомендуемые:
  • Windows 11, процессор 8+ ядер (Ryzen 7/9, Core i7/i9)
  • оперативная память 64 ГБ — агенты на Qwen3-Coder-Next
  • видеокарта NVIDIA с 12 ГБ видеопамяти (RTX 3060 12 ГБ и выше), драйвер R580 или новее
  • SSD

Драйвер видеокарты NVIDIA установщик не ставит: скачайте его с nvidia.com.
