## Изменения в коде

1. **Electron Fuses** (`electron-builder.json`): RunAsNode, NODE_OPTIONS, --inspect выключены; проверка целостности asar и
   загрузка только из asar включены. Проверено `@electron/fuses read`.
2. **Терминал** закрывается деревом процессов через `taskkill /T` (node-pty иначе запускает `fork` через Electron-as-Node,
   что отключено fuse'ом).
3. Лимиты: запись файла 5 МБ, история чата 20 МБ, журнал CSP-нарушений 20/с; OpenCode на свободном порту.
4. **Производительность**: строка состояния опрашивает только статус Ollama и загруженные модели раз в 10 с и не делает этого,
   пока окно скрыто; `nvidia-smi` — только при открытом MODEL VAULT; мигание курсора скрытого терминала отключается.
5. **SETUP** в MODEL VAULT: проверка Ollama, моделей, агентного варианта, OpenCode, Git, GPU; кнопки PULL (в ONLINE TOOLS)
   и CREATE `<model>-agent` (локально, `num_ctx 32768`).
6. **THIRD_PARTY_NOTICES.txt** генерируется из `node_modules` при каждой сборке (`tools/third-party-notices.mjs`): 32 пакета,
   все разрешительные лицензии (MIT, ISC, 0BSD, BlueOak, MPL-2.0/Apache-2.0, MIT/Apache-2.0).

## Открытые вопросы для вас

1. **Лицензия NETRUNNER.** В `package.json` стоит `MIT` — я поставил её в Фазе 1 по умолчанию. Это ваш продукт: решите, под какой
   лицензией его распространять (или сделать проприетарным), — я не добавлял файл LICENSE от вашего имени.
2. **ripgrep** — отложен вами; без него `grep`/`glob` агента не работают.
3. **Подпись кода** — нужен сертификат, если планируете раздавать установщик другим людям.
4. **Git.** Проект NETRUNNER до сих пор не под git (вы не просили коммитов).
